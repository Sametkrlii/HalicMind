# API rehberleri

- Katalog endpoint'leri: proje kökündeki `README.md`.
- Kayıt, e-posta doğrulama, JWT ve Swagger Authorize: `auth.md`.
- Akademik profil, hazırlık/yıllık dönemler, öneriler ve kişisel dersler: `academics.md`.
- Resmi akademik takvim aralıkları ve kapsam: `exams.md`.
- Derslere bağlı ödevler, teslim tarihleri ve tamamlanma takibi: `assignments.md`.
- Öğrenci arayüzü, aynı origin tarayıcı oturumu ve güvenlik: `frontend.md`.

Canlı OpenAPI şeması `/openapi.json`, etkileşimli Swagger `/docs` adresindedir.
